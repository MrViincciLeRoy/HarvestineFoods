# HarvestineFoods
## Project Overview
HarvestineFoods is a web application designed to provide food supply and retail services. The application offers various features such as navigation menu, about us section, and services section.
## Key Features
* Navigation menu with home, about us, and services sections
* Services section with supply, retail, and storage options
* Responsive design using Bootstrap
## Tech Stack
* HTML5
* CSS3
* Bootstrap
* Owl Carousel
## Installation
1. Clone the repository using `git clone https://github.com/username/HarvestineFoods.git`
2. Open the `index.html` file in a web browser
## Usage
1. Navigate to the home page using the navigation menu
2. Explore the about us and services sections
## Environment Variables
None required
